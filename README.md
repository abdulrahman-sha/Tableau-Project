# WFP Materials distribution in Lebanon


## Overview
- This tableau dashboard provides a comprehensive visualization of materials’ distribution in Lebanon from 2012 to 2021, based on WFP data,The project enables insights into the quantity and the price of each material and the total price of 29 materials for 10 years




## Getting Started

1. **Requirements:**
   - Tableau
  

2. **Usage Instructions:**
   - Open the tableau file.
     - <a href="[https://github.com/abdulrahman-sha/Excel-project/blob/main/COVID-19%20Arab%20world.xlsx](https://github.com/abdulrahman-sha/Tableau-Project/blob/main/wfp%20lebanon.twbx)">wfp lebanon </a>
   - Use the slicers to filter data by year or by material.
   - Observe automatic updates to charts for your selections.
   - Analyze different aspects of the disrtibution using the various visualizations.

## Data Sources

- Data is sourced from official WFP reports on kaggle.
